# Model-page Stage D1 review — elementary Small Systems and graph Ising

## Scope and page structure

Gaussian, single spin, binomial count and the existing finite graph-Ising models now use the common model-page hierarchy: action and collapsible settings in the sidebar; Run/Pause, Step, Reset, Save and current readings above a full-width featured display; zero to six optional **Measurements & diagnostics** tools; collapsible local inspection, exact references and retention details; and the existing mathematics and experiments at the bottom. The real scalar graph model retains `ScalarWorkspace`, `ScalarInspector`, its configuration URL and all existing numerical behavior until D2. D1 adds no named examples, new topologies or custom edge-presence editing; those belong to D3.

The elementary models feature their exact analytic density or exact probability masses together with the sampled histogram, and start with sample trajectory in the gallery. This keeps the binomial aggregate count distinct from a one-spin Bernoulli variable. Graph Ising features the original interactive SVG with vertex and bond selection, separate parallel edge labels, periodic-wrap marks, coupling sign/weight cues and latest-update highlights; magnetization distribution and trajectory start in the gallery. Selecting a graph item changes only workspace presentation state. Geometry and numerical coupling/field drafts are edited in a separate sidebar section. The editor still routes topology changes through `topologyKey` and compatible physical edits through isolated parameter segments. Read-only local field, conditional and bond calculations remain accessible in a collapsible inspection section.

`SmallToolDeck` maps the original seven `Inspector` plot renderers to shared `ToolDeck` assignments: distribution, trajectory, running mean, absolute error, acceptance, connected correlation and local conditional probability. The final two are graph-only. Graph cards choose among total/mean/absolute magnetization, action and site spins independently. Each distribution assignment owns a histogram toggle, initially on, keyed across feature/gallery exchange. Repeated distribution cards can disagree without changing worker measurements. The elementary current-variable diagram is an optional visualization rather than a sidebar decoration. `Refit axes` recomputes display limits from retained segments and exact references only; axes otherwise expand across compatible parameter changes. Viewport memory follows each assignment and target across remounts, and refit clears that memory for inactive cards. The legacy real-scalar inspector still says Fit All.

## Numerical ownership and validation

`SmallSystemsApp` is extracted from `App.tsx`; it still owns the existing `useSimulation` client, model configuration, run/segment actions, and selected graph site/edge. Worker snapshots remain authoritative for the current configuration, seeded RNG, warm-up, measurements and exact transition history. `GraphWorkspace.tsx` now exports separate configuration, inspection and editor components, while the exact finite-state reference is unchanged. No mathematical model, transition kernel, worker protocol, capture payload, archive schema or portable export module was edited. In particular, the graph action remains `S=−Σₑ Kₑsₜsₕ−Σᵢ bᵢsᵢ`: each bond record contributes once, including parallel periodic bonds and self-links. Direct whole-configuration draws, local Metropolis, heat bath and their update counts retain their original meanings; Monte Carlo updates are not physical time.

Existing unit tests continue to check actions, normalization, exact enumeration, local differences, samplers, pathological periodic geometries, seeded replay, statistics, bounded histories, and graph diagnostic references. The D1 browser regression compares two exported scientific captures from identical seeded Gaussian runs, changing tool assignments, histogram visibility and viewport only in one run; segment data, diagnostic records, current state, seed and capture update agree. Browser tests also cover the moved exact panels and graph editing/selection, six-card cap, feature exchange, target selection, independent histograms, viewport refit, keyboard controls, model-family switching, real scalar regression and 360 px no-overflow. Existing model, worker, archive and five-workspace tests remain in the complete pipeline.
