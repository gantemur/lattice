# Stage D2 — Real scalar graph model-page review

Stage D2 presents the existing one-to-four-site real scalar family through the Small Systems model-page layout. The sidebar contains the dimensionless action, a collapsible geometry and coefficient editor, sampler/seed settings, and schema-v1 configuration sharing. Run/Pause, Step, Reset and Save stay above a full-width featured tool. The current real-valued graph is featured by default; a marginal histogram and two-site scatter start in the gallery, with a bare local potential replacing scatter for a one-site model. Up to six gallery cards use the shared desktop two-column and phone detail/overview controls. Local site/bond inspection, exact/numerical references and teaching notes follow below in collapsible sections.

The former `ScalarWorkspace` responsibilities are split into `ScalarGraphVisualization`, `ScalarGraphInspection` and `ScalarParameterEditor`. The featured graph reads the applied worker vector and model. It retains numeric vertex values, fixed teal/ochre colors, latest-update highlight, oriented labeled bonds, parallel/wrapped/self links and pointer/keyboard selection. Small Systems owns the selected site and edge so selection survives moving the graph. The sidebar editor alone owns draft coefficients and the focusable coupling input; its Apply still invokes the pre-existing fixed-topology segment or changed-topology seeded-session path.

`ScalarToolDeck` is a typed presentation adapter around the existing `ToolDeck` and `ScalarPlot` renderers. Its ten plot IDs are `histogram`, `trajectory`, `mean`, `error`, `bare`, `conditional-potential`, `conditional-density`, `scatter`, `covariance` and `acceptance`. Histogram, trajectory and convergence plots can choose the supported site, square, pair-product, sum, mean and action targets where their existing reference rules permit. Bare and conditional views require an individual site and explicitly ask for one after an incompatible target. Scatter uses the first two sites and labels them; covariance and acceptance expose no spurious target selector. Assignment keys retain target, histogram visibility, viewport and 100/500/1000-update trajectory navigation through feature/gallery exchange. **Refit axes** replaces Fit All and affects only presentation. A hidden histogram without an applicable reference, or a coupled-quartic plot with no retained measurements, explains the missing display instead of showing an empty chart.

The action remains `Σᵢ(aᵢxᵢ²/2+λᵢxᵢ⁴/4−hᵢxᵢ)+Σₑκₑ(xₜ−xₕ)²/2`, with Gibbs weight `exp(−S)`. Distinct parallel edges each contribute once; self-links have zero gradient contribution. The conditional potential uses the current neighbors, while its normalized one-site conditional density is distinct from both the bare potential and the equilibrium marginal. Analytic finite-dimensional Gaussian precision, mean, covariance, pair moments, log Z and densities remain separate from controlled one-dimensional quadrature for independent quartic sites. Coupled quartic marginals and covariances remain sampled-only; no unsupported independent-sample uncertainty or mixing claim was added.

No numerical kernel, sampler, worker protocol, RNG policy, reference algorithm, histogram accumulation, capture schema or URL encoding was changed. Direct Gaussian, Gaussian coordinate heat bath and random-site Metropolis retain their original transition and warm-up rules. Fixed-topology parameter edits preserve compatible vector state and RNG while starting a new segment; topology edits and Reset restart a seeded session. The scalar share link continues to restore configuration only, never old measurements. Feature swaps, plot targets, histogram toggles and viewport operations compare equal complete scientific captures after seeded replay. The M1b trajectory window still labels global algorithmic updates, renders direct draws as points and local chains as steps, and does not reconstruct evicted transitions.

The complete `npm run check` pipeline passes: formatting, TypeScript, **352 unit tests** in 45 files, the production `/lattice/` build, and **226 passing browser tests** across desktop Chromium, 360 px phone Chromium and iPhone WebKit (two existing sweep-budget browser cases are intentionally skipped). Browser regression covers the default featured graph, one/two/four-site systems, ten plot IDs, target applicability, graph and editor selection, exact and quartic references, conditionals versus marginals, independent histogram controls, expanding axes, zero/one/two/six-card layouts, feature exchange, trajectory window retention, seeded capture equality and configuration URL round trips. The numerical unit suite remains unchanged; a malformed-link assertion was added to the existing schema-v1 test. `git diff --check` passes. Production screenshots under [screenshots](screenshots/) include coupled Gaussian references, a one-site double and tilted well, conditional density, four-site coupled quartic, featured trajectory and six-card desktop/360 px phone layouts. Visual review found the graph legible at all sizes, equations and matrices contained within their cards, and no horizontal page overflow. The first warm-up-only coupled-quartic capture exposed overly tall blank plot areas; those now have explicit compact no-data messages.

The source remains readable without a new generic framework: model/worker mathematics stay in their independent modules; the graph, inspection and editor each have one responsibility; the adapter owns presentation options; the established scientific plots still perform their original projections. The worker snapshot is the source of applied state. Stage D3 named examples and custom simple-graph editing, and later interacting fields, remain deferred.
