Comments explain ordinary measure, bond multiplicity, quartic conditional versus marginal, three-uniform overflow behavior, reference capabilities, worker ownership and segment coverage. They cover only periodic chains whose converted QM parameters fit existing bounds; generic coupled 2D fields have no exact reference. Spatial field archives, automatic criticality/continuum analysis and spatial HMC remain absent. The tested full spatial gradient and action provide the mathematical starting point for M4d2, but its integrator, correction, cadence, replay, equilibrium and UI tests still need implementation and validation.
