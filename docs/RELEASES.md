# Released capabilities and numerical validation

This summary connects the shipped product to its independently checkable science and browser regressions. The [specification](SPECIFICATION.md) is the current functional contract; [mathematical guides](SOURCE_GUIDE.md) connect equations to implementations. Historical milestone labels below identify the introducing feature, not separate numerical engines or current work orders.

## Released baseline

The M5e product baseline is [219c23b1b6dc6dcc5f9926544d3b6b53db6054a3](https://github.com/gantemur/lattice/commit/219c23b1b6dc6dcc5f9926544d3b6b53db6054a3), including the bounded-aspect-ratio XY canvas correction. Its [validation and Pages workflow](https://github.com/gantemur/lattice/actions/runs/38620416920) passed. The complete baseline pipeline recorded **970 unit tests in 97 files**, **418 production-browser passes and two existing skips**. The skipped cases are the phone/WebKit default sweep-budget scenario. Desktop Chromium, 360px Chromium and mobile WebKit exercise the static `/lattice/` deployment. Emulation does not establish physical-phone performance.

XY implementation [0ffa034](https://github.com/gantemur/lattice/commit/0ffa0345f0f79ab19d22fa644b2092d25d704516) also has a successful [hosted validation/deployment run](https://github.com/gantemur/lattice/actions/runs/38616201513). These are historical release facts, not a claim that every later documentation branch has been deployed. The unchanged [CI workflow](../.github/workflows/ci-pages.yml) validates pull requests and deploys only validated main builds. Reproduce the current checks with `npm ci`, `npx playwright install chromium webkit`, and `CI=1 npm run check` under Node 24.

## Ising lattices and diagnostics

M2 added physical `H/T` Ising on indexed square lattices, M3a added finite-volume fluctuation observables and bounded recent-window statistical diagnostics. The physical 2×2 exact reference handles the full supported temperature/field/coupling range independently of small-graph UI bounds. Exact and empirical correlation times use the actual observation cadence. Fully periodic spatial centering and open/mixed raw correlations remain distinct. The later 1D chain uses a scaled spatial transfer matrix; its bulk length is not a Monte Carlo mixing time.

## Z2 gauge

M5a samples counting measure on tiny oriented link complexes without gauge fixing. The open plaquette has `Z=16 cosh K`; the torus has `Z=256 cosh⁴K(1+tanh⁴K)`, with eight distinct bonds/four faces. [Mathematics](math/z2-gauge.md), [exhaustive invariance/enumeration](../src/models/z2Gauge.test.ts), [balance](../src/algorithms/z2GaugeSampler.test.ts), [ensemble tests](../src/engine/z2GaugeBenchmark.test.ts) and [browser tests](../tests/browser/z2Gauge.spec.ts) verify loops, transformations and worker ownership. [Desktop](screenshots/m5a-desktop.png), [phone](screenshots/m5a-phone.png). Fixed warm-up is not a mixing guarantee; winding products need not be conserved under Monte Carlo.

## XY spins

M5e uses site Haar angles, signed physical bonds and principal-lift oriented vortices. [Mathematics](math/xy-model.md), [independent angular oracle](../src/test/xyOracle.ts), [finite references](../src/models/xyReference.test.ts), [conditional-sampler tests](../src/algorithms/xySampler.test.ts), [ensemble benchmarks](../src/engine/xyBenchmark.test.ts), [worker lifecycle](../src/engine/xyRun.test.ts) and [browser tests](../tests/browser/xy.spec.ts) define the exact budgets, seeds and regression gates. Tiny torus `Z(.7,.7)=7.069401867411065`; physical parallel bonds yield the character sum with `2Kx,2Ky`. Opposite traversal negates one stored principal lift; near-antipodal faces are omitted with separate coverage. XY winding is not U(1) gauge curvature.

The released benchmark uses seeds 17, 271, 12345, 89231, with tiny cases at 500 warm-up sweeps, stride 4 and 6,000 measurements/seed. Torus mean S was −3.686985 (Metropolis) and −3.672918 (heat bath), against reference −3.663594. Large periodic 8×8 cases use warm-up 300, stride 2 and 1,500 measurements/seed. At zero coupling/source, vortex densities were .334036/.333349; at K=1.4 they were .000906/.000901, while common-angle exploration remained slow. These are historical regression observations with conservative empirical gates, not confidence intervals, evidence of equilibration, or BKT inference. Current tests remain the reproducible source of budgets and criteria.

The production browser regression also covers 2×32 and 32×2 canvas bounds, aspect ratio and pointer selection. No XY persistence, cluster/HMC, helicity modulus or criticality estimator is implied.
