# M4b review — Euclidean harmonic oscillator

**Scope and user-visible result.** This feature branch adds a selectable harmonic-oscillator mode inside the existing Fields & Paths workspace. Students can set `N,β,ω`, draw a periodic path, compare finite-lattice, continuum and sampled two-point correlators, inspect a cosh effective gap, and expand a transfer/reflection teaching panel. There is no fifth workspace, oscillator archive format, double well, φ⁴, HMC or server. [Desktop](screenshots/m4b-desktop.png) and [360 px phone](screenshots/m4b-phone.png) screenshots show the same seeded path experiment after changing ω, with two isolated sampled segments.

**Mathematical convention.** In units `ℏ=kB=m=1`, `a=β/N`, `H=p²/2+ω²x²/2`, and `S=Σ[(x_(j+1)−x_j)²/(2a)+aω²x_j²/2]` on `N` periodic time sites. The target uses ordinary `exp(−S)∏dx_j`, including a fluctuating constant mode of average-path variance `1/(βω²)`. The exact precision eigenvalues are `λ_k=aω²+4sin²(πk/N)/a`. The Fourier covariance agrees with a separate hyperbolic closed form and dense Cholesky on supported small cases. `Ω_a=2 asinh(aω/2)/a` is the exact finite-spacing transfer gap; `ω` is the continuum gap. Exact, continuum and sampled results are labeled separately. The sampled unconnected correlator averages `x_jx_(j+ℓ)` over translations and retained paths; it does not demean individual paths. The empirical effective gap is N/A when the acosh ratio has no valid real value and has no invented uncertainty.

**Transfer and normalization.** The symmetric Trotter kernel implements `e^(−aV/2)e^(−ap²/2)e^(−aV/2)`, not exact finite-a `e^(−aH)`. Its positivity as an operator follows from this factorization and the positive kinetic semigroup, not merely its positive kernel entries. The first two exact finite-spacing levels are `Ω_a/2` and `3Ω_a/2`. The raw Gaussian integral and physical trace differ by the kinetic factor `(2πa)^(−N/2)`; the determinant and `1/[2sinh(βΩ_a/2)]` trace calculations agree independently. A 49-node symmetric positive-trapezoid Nyström matrix on a disclosed finite coordinate interval illustrates the leading spectrum; its gap is approximate and may be inaccurate when the fixed grid under-resolves a sharply localized kinetic kernel. Exact `G_ij=C(i+j)` for positive half-circle indices has nonnegative eigenvalues within roundoff in checked cases. This finite illustration is not a proof of all Osterwalder–Schrader axioms; sampled Gram matrices can have small negative noise eigenvalues.

**Architecture and time.** [`oscillator.ts`](../src/models/oscillator.ts) validates physical parameters and maps them to the ordinary periodic field coefficients `r=aω²`, `κ=1/a`, `j=0`. The model discriminator lets [`FieldRun`](../src/engine/fieldRun.ts) use those derived coefficients without weakening the separate M4a Gaussian UI limits. It reuses the unchanged `fieldTransition` and `drawSpectralField` algorithms. [`oscillatorReference.ts`](../src/models/oscillatorReference.ts), [`oscillatorCorrelator.ts`](../src/observables/oscillatorCorrelator.ts) and [`oscillatorTransfer.ts`](../src/models/oscillatorTransfer.ts) are pure, React-independent mathematics. The worker retains at most eight segments and 256 plotted vectors per segment, while pair-product aggregates span all retained measurements in each surviving segment. `β/ω/sampler` edits at fixed `N` preserve the configuration and RNG but start a new measurement segment; changing `N`, switching models and Reset start a seeded session. The local samplers use `N` elementary site updates per nominal Monte Carlo sweep; a spectral update independently redraws the entire path with exactly `2N` uniforms. The path horizontal axis is **Euclidean coordinate time**; Run/Step counters are **algorithmic Monte Carlo time**, never real physical evolution.

**Independent numerical evidence.** Four-site direct action and precision calculations check the field map and periodic bond count; oscillator coefficients outside the standalone Gaussian UI bounds run at `N=64,β=2,ω=0.25`. Dense covariance, Fourier sum and closed correlator agree, including odd-N midpoint reflection. Refinement tests check second-order convergence toward the continuum. Partition determinant and transfer trace agree, as do the analytic gap and a refined finite-grid eigenvalue ratio. A hand-checkable `[[2,1],[1,2]]` tests the small Jacobi solver. Several reflection Gram matrices are positive semidefinite to roundoff. Direct path loops match full-segment pair projection after 24 of 280 vectors have been evicted. Seeded Step versus unequal batches, `2N` uniform consumption, local full-action differences, warm-up/stride, segment separation and a 2,000-draw independent correlator ensemble are tested. Existing M4a sampler tests remain part of the full suite. The [mathematical guide](math/euclidean-oscillator.md) links every principal equation to code and tests and offers small exercises.

**Browser and resource review.** Production desktop Chromium, 360 px phone Chromium and mobile WebKit exercised the mode, path, correlator, effective-gap control, transfer panel, parameter segments, Reset replay, fine `a=1/32` with `κ=32`, local heat bath and no horizontal overflow. Settings collapse and controls are accessible by labeled form elements and touch targets. At most 64 path sites, eight segment pair matrices and 256 recent vectors per segment bound worker records. The 49-node quadrature is recomputed only when applied physical parameters change; the direct Fourier reference and draws use the existing small-`N` DFT. No dependency was added. The production main chunk is about **533.3 kB**, above the existing 500 kB advisory but still a static GitHub Pages build under `/lattice/`; no code-splitting complexity was introduced solely for the warning.

**Readability assessment.** The physical action, exact reference, observable projection, transfer calculation, input form, analytical panel and workspace view have separate modules. Comments explain normalizations, time coordinates, model validation and worker-owned state near their implementations. Small independent examples make the science inspectable without trusting the view. [`SOURCE_GUIDE.md`](SOURCE_GUIDE.md) adds an ordered M4b reading path. The existing M4a numerical kernels and previous workspaces were not rewritten.

**Validation.** `npm run check` passed: Prettier, TypeScript, **338 unit tests**, production build and **154 production browser tests** across desktop Chromium, phone Chromium and mobile WebKit (**2 existing skips**). The main-chunk advisory remains nonfatal. Screenshots were captured by the production browser tests.

**Remaining limits.** Local-chain correlator estimates can be biased by insufficient warm-up and strongly correlated; no ESS-based or nonlinear-gap uncertainty is claimed. The quadrature uses a finite coordinate cutoff and fixed node count, so its gap is a demonstration, not a replacement for the analytic reference. Gaussian-field experiment archives are still deferred; switching modes starts a new live session. M4b covers only the harmonic oscillator.
