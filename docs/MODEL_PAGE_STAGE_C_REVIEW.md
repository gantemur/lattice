# Model-page Stage C review — 2D Ising Lattice Systems

## Page and state ownership

Lattice Systems now follows the QM/Fields page hierarchy. The left sidebar presents the nearest-neighbor Ising Hamiltonian, Gibbs/action convention and collapsible geometry, physical-parameter and sampler draft. The main column retains Run/Pause, Step, Reset, both Save actions, immediate m/e/M/H readings and the actual latest local transition. A full-width **Spin configuration** is featured by default; **Measurements & diagnostics** starts with signed-magnetization and physical-energy-density histories and accepts zero to six optional cards. Parameter segments, finite measurements, exact references and the M3a diagnostic panel are under **Technical details, exact references & diagnostics**. The separate collapsible mathematics/exercises section retains all five classroom experiments.

The original Canvas renderer was extracted into `src/app/CanvasLattice.tsx`. Its teal/orange pixels, selected-site outline, yellow latest-update outline, +1/−1 legend, 5×5 neighborhood, pointer and numeric selection, periodic/open explanations and 640-pixel maximum native image are preserved. The selected site is owned by `LatticeSystems`, so a ToolDeck feature/gallery exchange can remount the canvas without losing selection. There is one mounted canvas per active assignment; selecting a site never posts a worker command. The responsive feature does not squeeze the image into a chart viewport.

`LatticeToolDeck.tsx` is a small static Ising adapter around the existing `ToolDeck`, not another card manager. The 16 plot IDs remain `m-history`, `abs-history`, `e-history`, `m-histogram`, `e-histogram`, `m-mean`, `abs-mean`, `e-mean`, `acceptance`, `m-acf`, `abs-acf`, `e-acf`, `m-blocking`, `e-blocking`, `spatial-x` and `spatial-y`. `LatticePlots.tsx` retains their scientific projections and notes. The compact update-outcomes analysis is gallery-only; the other plots can be featured. A plot type can be used in more than one placement. ToolDeck keeps whole-assignment exchanges, explicit featured replacement, direct Add, collapse, expansion, reorder, removal and the independent six-gallery-card cap. The phone still has one detail card and optional compact overview.

The shared 100/500/1000 **nominal-sweep** history window belongs to the adapter, not a plot renderer or worker. Older, Newer, Follow latest and End sweep affect every active history view. History plots continue to draw separate polylines per parameter segment and only from retained measurements. The earliest retained sweep limits backward navigation; no missing measurements are invented. The toolbar disappears when only unrelated views are active. Spatial maximum displacement is instead stored by keyed spatial-tool assignment, follows that assignment through a feature exchange and is removed with it. Worker-side positive-axis spatial accumulation is unchanged: fully periodic geometry shows the established plug-in connected form, while open/mixed geometry shows raw pair correlation.

## Scientific and archive invariants

The physical Hamiltonian remains `H = −Jx Σx sᵢsⱼ − Jy Σy sᵢsⱼ − h Σᵢsᵢ`, with `S=H/T`, `m=M/N` and `e=H/N`. One nominal sweep is N random-site attempts with replacement, not physical time. No model, sampler, worker, observable, archive, sweep or serialized-format module changed in this stage. Full-segment moments, histograms, fluctuations and bond products retain their coverage; histories and diagnostic rings remain bounded. Applying fixed-geometry physical changes keeps spins/RNG and starts a new measurement segment with its existing warm-up policy. Geometry changes and Reset start seeded sessions. Run/Pause and in-flight batches retain their prior behavior.

The technical details still expose means and variances of m, |m|, e, m² and e²; χ, Binder U₄, cᵥ and directional bond products; stable physical-parameter 2×2 exact enumeration, probabilities and log Z for open/mixed/periodic boundaries; and the M3a empirical/recent-window and exact small-chain statistical diagnostics. Periodic 2×2 keeps eight distinct bond records. The infinite-volume Tc reference remains conditional on positive Jx/Jy and zero field and is not claimed as a finite-volume singularity. Recent-window SE is not presented as an uncertainty for the full-segment mean. Save current/available segments and Experiments captures keep their established provenance and bounds.

## Readability and next boundary

The code follows the repository reading order: `latticeIsing`/`latticeExact` define physics, `LatticeRun` owns segments and measurements, `LatticeClient` owns worker scheduling, and the Stage C React adapter only reads snapshots. `CanvasLattice` contains drawing and selection, `LatticeToolDeck` owns presentation-only history/spatial choices, `LatticePlots` owns the model-specific projections, and `ToolDeck` owns generic assignment operations. Comments at state boundaries explain why selection and display settings live above remountable renderers. The numerical modules remain independently testable without React.

Small Systems and Experiments are not migrated. Stage D's named-example catalog, graph editing, Fit All label and histogram controls remain separate work. Stage C adds no new physical model, sampler, confidence estimator or general tool/plugin framework.
