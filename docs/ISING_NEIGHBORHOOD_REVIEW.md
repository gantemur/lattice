# Ising Local 5×5 neighborhood teaching-tool review

**Status:** validated for release, 2026-10-12. This is a presentation-only addition after Stage D2.

The full spin canvas remains the default featured Lattice Systems display; signed magnetization and physical energy-density histories remain the two default gallery cards. Local 5×5 neighborhood is a separate Visualization choice in the featured selector and every gallery card selector. It shows a readable selected-site image, numeric coordinate controls, a distinct center outline, open-boundary cells, and periodic images. The canvas no longer carries a permanently expanded 5×5 grid. Both views share the `LatticeSystems` selected site, so pointer and numeric selection, card collapse, feature exchange, navigation and ordinary parameter-segment changes retain the same inspection target. Geometry changes and Reset retain their seeded-session selection reset.

`src/app/neighborhoodCells.ts` is the pure mapping from displayed offsets to row-major physical site indices. It wraps each periodic axis independently and marks out-of-range cells on open axes. A periodic 2×2 has repeated displayed images of the same physical spin; the 25 cells are not new degrees of freedom. The indexed lattice and its parallel bond records remain authoritative for energy and updates. The component reads the existing spin snapshot and does not issue worker commands or consume randomness.

Validation: `npm run check` passed with formatting, typecheck, 356 unit tests, production build and 241 browser tests across desktop Chromium, 360px phone Chromium and mobile WebKit (two existing browser skips). `git diff --check` passed. Mapping tests cover 32×32 interior/corner, fully periodic and mixed boundaries, and repeated 2×2 images. Browser tests cover default layout, every selector retaining the 16 scientific plot IDs, gallery/featured exchange, canvas-to-neighborhood and numeric shared selection, open and periodic geometry, card collapse, navigation, parameter segments, phone detail/overview and no horizontal overflow. A seeded control comparison and two exported scientific captures confirm that display changes leave updates, measurements and RNG behavior unchanged.

Visual review inspected the [default desktop](screenshots/ising-neighborhood-default-desktop.png), [half-width gallery](screenshots/ising-neighborhood-gallery-desktop.png), [featured view](screenshots/ising-neighborhood-featured-desktop.png), [open corner](screenshots/ising-neighborhood-open-corner-desktop.png), [periodic 2×2](screenshots/ising-neighborhood-periodic-desktop.png), and [360px phone featured view](screenshots/ising-neighborhood-featured-phone.png). Teal/orange cells, the dark center outline and pale outside cells remain legible within half-width and phone layouts. The neighborhood is intentionally a fixed 5×5 teaching image; zoom, bond overlays and new local observables remain future work.

No M3/D3 catalog work, new observable, sampler, worker protocol, mathematical model, archive schema or scientific plot renderer changed.
