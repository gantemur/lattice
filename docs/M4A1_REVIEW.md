# M4a1 review — massive Gaussian lattice fields

The feature branch adds **Fields & Paths** as a fourth static, worker-backed workspace. M4a1 covers a real massive Gaussian field on 1D chains and 2D rectangles. Direct independent draws, random-site conditional heat bath and random-site Metropolis share one transition kernel between Run and Step. The existing workspaces, archive schemas and sweep protocol are unchanged.

## Mathematical contract and reference

The target weight is `exp(−S)` relative to ordinary `∏ᵢdφᵢ`, with

`S=(r/2)Σᵢφᵢ²+(1/2)Σ_bκ_b(φ_tail−φ_head)²−jΣᵢφᵢ`.

Here `0.05≤r≤20`, `0≤κx,κy≤10`, and `|j|≤10`; there is no extra inverse-temperature factor. A bond exists only along a positive axis with an existing neighbor or periodic wrap. Open boundaries do not pin field values. Each periodic length-two axis retains two parallel bonds. The precision is `Q=rI+` the weighted bond Laplacian, so the supported model is strictly positive definite. The dense reference, limited to 64 sites, factors `Q=LLᵀ`, solves `Qμ=j1` and `QC=I`, checks the full `QC≈I` residual, and computes `log Z=(N/2)log(2π)−Σᵢlog Lᵢᵢ+(1/2)j1ᵀμ`. “Exact” means the finite Gaussian analytic result up to floating-point rounding.

The direct sampler draws two uncached Box–Muller uniforms per field component. A local heat-bath update draws a site uniform and two normal uniforms; Metropolis draws site, proposal and decision uniforms, even when rejected. One direct update replaces the entire field. One local update selects one random site with replacement; `N` local updates are one *nominal* sweep, not physical time. Independent draws have no acceptance rate or local-sweep unit. Coordinate heat bath has no accept/reject test. A fresh zero-valued local configuration is not a measurement.

## State, measurements and display

The field worker owns configuration, RNG, update count, warm-up, moments and recent numeric history. React receives immutable snapshots and may select a site, pair or fixed display scale without sampling. The 1D profile and 2D heatmap use a user-controlled `±` scale; out-of-range values are clipped and counted. The site inspector separates on-site and incident bond action/gradient terms, conditional mean/variance, equilibrium marginal variance, and latest actual update. It compares exact and segment-sampled site means, pair products and connected covariance. The sampled covariance is the centered `1/N` plug-in value `〈φᵢφⱼ〉−〈φᵢ〉〈φⱼ〉` from one segment, shown only after two measurements; it is distinct from an `N−1` sample variance and has no unsupported local-chain error bar.

Direct draws measure each update. Local methods use whole-sweep warm-up and measurement stride per segment. Changing settings on fixed geometry preserves field and RNG and starts a fresh segment; geometry changes and Reset begin a new session using **Seed on Reset**. At most eight segments are kept. Each retained segment holds full online site, spatial-average and action-density moments plus pair-product sums; each holds at most 256 recent full field vectors for plotting. Eviction does not truncate aggregate estimates. Bounded recent history is shown as separate colored points by segment and never reconstructs missing updates. Snapshots include seed, settings, update and segment counts, warm-up and retained coverage for eventual portable capture; M3b1/v2 archives are unchanged.

## Validation and performance

The hand-checkable two-site open example has `Q=[[5,−3],[−3,5]]`, `C=[[5,3],[3,5]]/16`, `μ=(1,1)` and a separately calculated log partition. Tests cover the second periodic bond, periodic 2×2 and mixed-boundary multiplicities, anisotropic matrices, symmetry and positive diagonals, the `QC≈I` identity, conditional law, signed local-action recomputation, finite-difference gradients, zero-coupling agreement with the existing 0D and graph Gaussian references, and statistically tolerant direct-draw moments. The 8×8 periodic case at `r=0.05`, `κx=κy=10` validates the supported dense limit. Seeded Step/batch replay, sampling-independent snapshots, warm-up/stride, segment isolation, bounded histories, rejected Metropolis moves, draw counts, invalid inputs and stale worker commands have regression tests.

The dense reference uses an `O(N³)` factorization and covariance solve and an `O(N³)` residual check only on model or segment creation; local transitions use the incident bonds. With `N≤64`, full pair cross-sums are `O(N²)` per retained measurement and the maximum retained vector history is eight times 256 times 64 numbers. The production build has an approximately 505 kB main JavaScript chunk (about 150 kB gzip), just above Vite’s warning threshold; no new package dependency was needed. These are deliberate small-browser limits, not a scalable field-theory engine.

`npm run check` passed: Prettier, TypeScript, 294 unit tests across 38 files, production Vite build, and 139 browser cases across desktop Chromium, phone Chromium and iPhone WebKit (two existing platform-specific cases intentionally skipped). The M4a1 production browser cases exercise 1D/2D geometry, direct, heat bath and Metropolis updates, covariance display, display-only seed replay and parameter isolation. ## Source-readability assessment

The suggested reading order is [the mathematical walkthrough](math/gaussian-fields.md) → `src/domain/fieldLattice.ts` → `src/models/gaussianField.ts` → `src/models/gaussianFieldReference.ts` → `src/algorithms/gaussianFieldSampler.ts` → `src/engine/fieldRun.ts` → `src/workers/field.worker.ts` and `src/engine/fieldClient.ts` → the small `Field*` React modules. [SOURCE_GUIDE.md](SOURCE_GUIDE.md) also maps the earlier model families. The equation-bearing numerical files are independent of React; two-site and 2×2 tests show expected values without trusting the implementation under test. Comments explain ordinary-measure normalization, parallel bonds, Cholesky orientation, RNG draw order, segment ownership and the difference between complete aggregates and recent plot data. The end-of-pass review removed an unnecessary discriminated-union cast from controls, repaired worker recreation after a crash, and made the displayed local action and gradient terms correspond to the actual functions. It found no reason to rewrite the earlier numerical modules or add a generic numerical framework.

Remaining limits are intentional: `r=0` has no zero-mode convention here; Fourier draws, oscillator paths, `φ⁴`, HMC and field archive integration await later milestones. A local-chain mean is not assigned an independent-sample standard error, and fixed warm-up alone does not demonstrate equilibrium. The capped segment history can evict old displays while preserving no portable copy until M4e.
